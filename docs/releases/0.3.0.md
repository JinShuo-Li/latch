# Latch 0.3.0

This release brings the browser interface to the published Linux and Windows binaries, sharing the same kernel, durable sessions, approvals and mandatory sandbox as the terminal interface.

- Start with `latch --web`; use `--web-port` for a local port or `--ssh` for SSH forwarding instructions.
- Configure providers and models, resume sessions, send images, inspect diffs, approve tools and steer running tasks from the browser.
- Manage and delete session history from the TUI or Web interface. Deletion hides sessions while retaining raw events and validation evidence.
- See provider and tool activity in both interfaces, with elapsed and inactivity times. Reasoning text is not exposed.
- Improved terminal wrapping, Markdown tables and scrolling performance; the browser also renders Markdown tables.
- Fixed managed-process exit reconciliation and completion reporting, and excluded kernel snapshots from working-history rotation pressure. The default conversation-history threshold is now 64,000 tokens, based on recorded calibration; durable history remains intact.
- OpenCode Go DeepSeek V4.1 Flash supports image input by default.

## Install or upgrade

Linux:

```sh
curl -fsSL https://jinshuo-li.github.io/latch/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://jinshuo-li.github.io/latch/install.ps1 | iex
```

The installers resolve the latest stable release and verify its archive against `SHA256SUMS`. Linux requires glibc 2.35+, Bubblewrap, ripgrep and Git. Windows requires Git, ripgrep and a user-owned NTFS workspace; the native sandbox is embedded.

## Known Windows limits

Large or actively changing workspaces can have high sandbox startup costs. Existing objects must permit temporary ACL changes; foreign-owned objects can fail closed. Sandboxed access to local development servers and broader recovery/compatibility cases remain qualification gaps. Use focused, stable, user-owned workspaces. See [Windows diagnostics](https://github.com/JinShuo-Li/latch/blob/v0.3.0/docs/WINDOWS_DIAGNOSTICS.md).
