# Latch 0.3.1

This patch release completes scoped Windows workspace and localhost support while preserving the mandatory native sandbox.

- Read and modify ordinary NTFS workspace files without per-object source ACL changes or WRITE_DAC, including host-readable foreign-owned files. Sensitive paths remain protected and unsafe cases fail closed.
- Reduce command startup preparation on large mutable workspaces. A 100,033-object disposable NTFS fixture passed with unchanged source ACLs; an entire live home directory remains unqualified.
- Support explicitly Network-authorized localhost TCP clients/listeners and UDP over IPv4/IPv6 without machine-wide firewall changes or broad loopback exemptions.
- Fix headless PowerShell 7 extension startup and native cmd UTF-8 output for Chinese filenames.
- Close the DOS 8.3/long-path sensitive-mask bypass and strengthen sensitive ACL sealing, cancellation and recovery regressions. Unsupported x86 descendants fail closed.

## Validation

Linux release checks and native Windows security, runtime, developer-tool and Web transport checks pass. Real paid OpenCode Go acceptance completed a Windows coding workflow with 21 model requests, 29 successful tool calls and durable completion Verified. Independent checks confirmed unchanged supplied tests and exact Unicode/localhost artifacts. See [Windows evidence](https://github.com/JinShuo-Li/latch/blob/v0.3.1/docs/WINDOWS_DIAGNOSTICS.md).

## Install or upgrade

Linux:

```sh
curl -fsSL https://jinshuo-li.github.io/latch/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://jinshuo-li.github.io/latch/install.ps1 | iex
```

Installers select the latest stable release and verify SHA256SUMS. Linux requires glibc 2.35+, Bubblewrap, ripgrep and Git. Windows requires x64 Windows, Git, ripgrep and a focused NTFS workspace; the native sandbox is embedded.

## Remaining Windows qualification

Physical power-loss recovery, hostile host races, an entire live home directory and broader application/architecture compatibility remain outside the proven scope. Private LAN needs separate endpoint qualification. See [issue #7](https://github.com/JinShuo-Li/latch/issues/7). There is no unsandboxed fallback.
