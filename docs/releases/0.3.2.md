# Latch 0.3.2

Agent Skills and MCP tools now integrate with Latch's durable session model,
conservative permissions and mandatory platform sandbox.

- Discover Agent Skills from workspace/user `.latch`, `.agents` and `.claude`
  skill directories. Load YAML-frontmatter `SKILL.md` instructions and bounded
  resources on demand without changing the stable system prompt.
- Connect operator-configured MCP tool servers over sandboxed newline stdio or
  Streamable HTTP (JSON/SSE). Support modern 2026-07-28 and legacy initialization
  protocols, bounded discovery/calls, cancellation and deterministic cleanup.
- Inspect skills and servers through CLI/TUI diagnostics. Child agents own
  independent MCP clients. Server annotations never grant permissions; external
  calls invalidate older validation evidence before execution.

See [configuration, compatibility and limits](../SKILLS_AND_MCP.md).
Existing extensions, providers, durable history and evidence ownership remain
unchanged. Optional MCP interactions and deprecated HTTP+SSE endpoint transport
are not advertised. This release does not add Mods, marketplaces or computer use.

Binary release targets are Windows x86_64, Linux x86_64, and Linux ARM64.
Both Linux builds use Ubuntu 22.04 with a glibc 2.35+ baseline. The Linux
installer detects the host architecture and selects the matching archive.
