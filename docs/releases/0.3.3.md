# Latch 0.3.3

Latch now ships native Apple Silicon macOS binaries alongside Linux and Windows.
This release also hardens command execution, multi-agent concurrency, provider
streaming, setup, and installation.

- **Apple Silicon macOS:** mandatory Seatbelt execution backend, native ARM64
  archive and automatic Unix installer selection. Commands retain capability
  approval, protected credentials/state and Git metadata, bounded output and
  sandbox inheritance. The binary is ad-hoc signed after stripping.
- **Real terminal qualification:** Linux and macOS CI start the actual TUI in a
  PTY, type and edit prompts, execute a sandboxed tool, render two replies,
  switch mode, resize and verify clean exit plus terminal restoration. Actual
  screen captures are uploaded. Native macOS CLI and Web transport tests pass.
- **Windows installation:** PowerShell 5.1 and 7 compatibility, including
  strict-mode release redirects, bounded retries after transport interruptions,
  and SHA256 verification without Get-FileHash.
  The documented one-liner prepares the current terminal PATH and verifies the
  installed binary. Persistent PATH and existing configuration remain intact.
- **Execution safety and reliability:** correct Git rename parsing for undo,
  refusal of filesystem-root outside-write scopes, and call-specific approvals.
  Managed output stays bounded during execution, preserves split UTF-8, and
  explicitly marks incomplete logs when saving output fails.
- **Multi-agent correctness:** serialize first worker starts and reconstruction,
  preserve initial delegation, prevent concurrent group reloads from overwriting
  updates, and avoid shutdown busy loops.
- **Providers and media:** report malformed Responses tool arguments, parse
  mixed-ending SSE frames correctly, and make identical concurrent image
  ingestion race-free.
- **Interactive UI and setup:** restore created-file previews, preserve rejected
  setup values with explanations, honor effective provider/model settings and
  wire values, and improve approval, interrupt and printed-answer handling.
- **Engineering:** recover interrupted reference fetches, fix benchmark and
  dogfood edge cases, protect site build output, pin workflow actions, and
  expand Windows security and Cargo coverage.

Release targets: Linux x86_64 and ARM64 (glibc 2.35+), Windows x86_64, and Apple
Silicon macOS. macOS 15 ARM64 is natively tested; macOS 14 is the deployment
baseline and still needs runtime qualification. Intel Macs, Windows ARM64 and
musl/Alpine binaries are not provided. macOS Developer ID signing/notarization
and Windows ConPTY qualification remain outside this release.

See [installation](https://github.com/JinShuo-Li/latch/blob/v0.3.3/docs/INSTALL.md), [macOS qualification](https://github.com/JinShuo-Li/latch/blob/v0.3.3/docs/MACOS.md), and
[real TUI tests](https://github.com/JinShuo-Li/latch/blob/v0.3.3/docs/TUI_TESTING.md). No provider credentials or paid calls are
needed by the deterministic acceptance tests.
