# Latch 0.3.4

## Highlights

- ChatGPT subscription sign-in through `latch login` or `/login`, with protected
  local OAuth credentials and subscription Responses transport. API billing
  remains separate; no automatic API-key fallback.
- Provider setup adds accounts without replacing existing families or legacy
  defaults. Multiple instances receive distinct identifiers.
- One provider credential covers its model catalog. New setup enables the full
  catalog; `/model all` clears local filters and `/model refresh` fetches current
  service metadata. ChatGPT catalog queries automatically follow the official
  stable Codex version, with cached and embedded fallbacks.
- Historical model descriptors remain available for resume while current service
  listings drive selection. Retired experimental models no longer populate
  offline pickers.
- Empty `/skills` and `/mcp` results now explain their status and setup options.
- `latch uninstall` offers program-only removal by default, explicitly confirmed
  removal of local data/configuration, or cancellation. Windows supports deferred
  self-removal; native tests use disposable binaries.

## Compatibility

Linux, Windows x86_64, and Apple Silicon macOS retain their mandatory sandbox
backends. Provider permissions and quotas remain server-owned. Startup and
`doctor` stay offline. Existing sessions and configured defaults are preserved.
