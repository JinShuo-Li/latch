Install. Then open a terminal.

Download a precompiled binary. No Rust toolchain needed. The installer checks SHA256 before installing.

Linux

x86_64 · glibc 2.35+

BASH

curl -fsSL https://jinshuo-li.github.io/latch/install.sh | bash

Installs to ~/.local/bin. Runtime requires Bubblewrap, ripgrep, and Git.

Debian / Ubuntu prerequisites
sudo apt update && sudo apt install bubblewrap ripgrep git

Windows

x86_64 · native MSVC build

POWERSHELL

irm https://jinshuo-li.github.io/latch/install.ps1 | iex

Installs to %LOCALAPPDATA%\Programs\Latch\bin. Requires Git, ripgrep, and a user-owned NTFS workspace.

Native sandbox included. No WSL or compiler needed.

The installer leaves PATH unchanged. For the default install directory, run this in the current PowerShell terminal:

$env:PATH = "$env:LOCALAPPDATA\Programs\Latch\bin;$env:PATH"
latch --version

For future terminals, add %LOCALAPPDATA%\Programs\Latch\bin to your user Path in Windows Environment Variables, then reopen PowerShell. Use your chosen directory if you customized the install location.

Run latch, use /setup to choose a provider and model, then run latch doctor to check your configuration.

What execution
commits to.

The boundary is part of the tool.
So is the evidence.

No sandbox, no command.
Bubblewrap on Linux. Native AppContainer on Windows. Inspection commands have read-only filesystem access. If the boundary is unavailable, execution stops.
Resume with the history intact.
The append-only session log keeps task state, tool results, and evidence. Pick up the work without losing how you got there.
Change the code, check it again.
A validation pass belongs to the workspace state it checked. Later writes make it stale. Running managed processes block certification until they exit and the work is revalidated.
