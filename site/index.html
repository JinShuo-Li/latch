01 / RUNTIME MODEL

State is explicit.

Latch keeps the run inspectable: what happened, what changed, and what was actually verified.

01

Durable history

Sessions resume from an append-only event log. Task state, tool results, and evidence survive the process.

02

Bounded execution

Commands run in Bubblewrap. Mode, safety, and permissions are separate controls; there is no unsandboxed fallback.

03

Evidence with a generation

Validation belongs to the workspace state it checked. A later write makes the earlier pass stale.

04

Terminal-native control

Inspect the transcript and task state, steer a running turn, or resume the session from the CLI.

03 / INSTALLATION

Build it. Run it. Resume it.

Stable Rust and a C toolchain are required. The runtime needs Git, bwrap, and rg.

Prerequisites

Install stable Rust ↗, then the system packages. For Debian or Ubuntu:

DEBIAN / UBUNTU
sudo apt install bubblewrap ripgrep git build-essential

Other distributions: install the equivalent packages. Latch does not run commands without bwrap.

01 / INSTALL
git clone https://github.com/JinShuo-Li/latch.git
cd latch
cargo install --path crates/latch-cli --locked
02 / CONFIGURE

Run latch. Enter /setup in the TUI to choose a provider, credential source, and model.

03 / CHECK
latch doctor

Read-only preflight. It checks local prerequisites and config without contacting the provider.
