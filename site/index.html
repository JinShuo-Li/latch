GET STARTED / 03

From source to
your terminal.

Latch is Linux-first. Install stable Rust, a C toolchain, Git, bwrap, and rg first.

DEBIAN / UBUNTU
sudo apt install bubblewrap ripgrep git build-essential
Read the full guide ↗
01

Install the CLI

git clone https://github.com/JinShuo-Li/latch.git
cd latch
cargo install --path crates/latch-cli --locked
02

Choose a model

Run latch, then enter /setup in the TUI. Choose a provider, credential source, model, and reasoning effort.

03

Check your setup

latch doctor

doctor checks local prerequisites and config without contacting the provider.
