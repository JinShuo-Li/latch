Latch

A coding agent for your terminal and browser, built around verifiable execution boundaries.

Written in Rust with mandatory OS-native command sandboxing, durable SQLite event history, and validation tied directly to the workspace generation it checked. Bring your own model provider or subscription.

System profile · v$version

Execution boundary
Linux Bubblewrap, Windows native AppContainer & file/socket brokers, macOS Seatbelt. No unsandboxed fallback.
Durable continuity
Append-only SQLite event store with hysteretic epoch rotation, FTS recall, and full resume equivalence.
Validation contract
Passed checks certify only the observed workspace generation; later edits or active background writers invalidate stale passes.
Interfaces & protocols
Ratatui terminal UI, local loopback Web UI (--web), headless CLI, Agent Skills, MCP, and optional read-only LSP.

Deployment

Installation

Full install guide →

Precompiled binaries for Linux x86_64/ARM64, Windows x86_64, and Apple Silicon macOS. The installers verify SHA256 checksums before placing the binary.

Linux / macOS

Bash · automatic architecture selection 
curl -fsSL https://jinshuo-li.github.io/latch/install.sh | bash

Linux requires Bubblewrap, ripgrep, and Git; Apple Silicon macOS uses Seatbelt, ripgrep, and Git. Both install to ~/.local/bin; follow the installer’s PATH instructions.

Windows

PowerShell 5.1 or 7 · TLS 1.2 
& { $$ErrorActionPreference='Stop'; [Net.ServicePointManager]::SecurityProtocol=[Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12; irm -DisableKeepAlive https://jinshuo-li.github.io/latch/install.ps1 | iex; $$env:Path="$$env:LOCALAPPDATA\Programs\Latch\bin;$$env:Path"; latch --version }

Requires Git, ripgrep, and a user-owned NTFS workspace. The native sandbox is included. Add the install directory to your user PATH.

Architecture & invariants

How Latch works

System architecture →
Sandboxed commands
Bubblewrap on Linux, Seatbelt on macOS, and native AppContainer on Windows. Command execution stops if the sandbox is unavailable. Boundaries and limits →
Durable sessions
Session events persist in SQLite. Working-history rotation keeps the original record available; resume restores task state and evidence. Sessions and continuity →
Recorded validation
A pass applies to the workspace state it checked. Later writes make it stale, and active managed processes block certification. Validation semantics →
Multi-agent support
A root agent can delegate to independent child sessions. Child reports and group coordination do not certify the root task. Agent coordination →
