Latch

A coding agent for your terminal and browser.

Written in Rust, with mandatory command sandboxing, durable sessions, and validation tied to the workspace it checked. Use your own model provider.

Installation

Full install guide →

Precompiled binaries for Linux x86_64/ARM64 and Windows x86_64. The installers verify SHA256 checksums.

Linux Bash · glibc 2.35+

curl -fsSL https://jinshuo-li.github.io/latch/install.sh | bash

Requires Bubblewrap, ripgrep, and Git. Installs to ~/.local/bin; follow the installer’s PATH instructions.

Windows PowerShell

irm https://jinshuo-li.github.io/latch/install.ps1 | iex

Requires Git, ripgrep, and a user-owned NTFS workspace. The native sandbox is included. Add the install directory to your user PATH.

Run latch in your project, use /setup to choose a provider and model, then check prerequisites with latch doctor. Build from source →

How Latch works

Sandboxed commands
Bubblewrap on Linux; native AppContainer on Windows. Command execution stops if the sandbox is unavailable. Boundaries and limits →
Durable sessions
Session events persist in SQLite. Working-history rotation keeps the original record available; resume restores task state and evidence. Sessions and continuity →
Recorded validation
A pass applies to the workspace state it checked. Later writes make it stale, and active managed processes block certification. Validation semantics →
Multi-agent support
A root agent can delegate to independent child sessions. Child reports and group coordination do not certify the root task. Agent coordination →
